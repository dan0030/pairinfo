# PAIRFRAME · 페어틀 메이커

2인 페어의 서사를 정리하는 **페어틀**을 블록처럼 쌓아서 만드는 웹 도구입니다.
빌드 과정 없는 정적 사이트라 GitHub Pages에 그대로 올리면 됩니다.

## 사이트 열기 (GitHub Pages)
1. 저장소 **Settings → Pages**
2. **Source: Deploy from a branch**, 브랜치(예: `main`) / 폴더 `/ (root)` 선택 후 저장
3. 잠시 뒤 `https://<아이디>.github.io/pairinfo/` 에서 열립니다.

로컬에서 볼 때는 `python3 -m http.server` 후 `http://localhost:8000` 으로 여세요.

## 기능
- **템플릿 2종**
  - 간략: 페어명(+ 페어 키워드 해시태그) · 관계도 화살표(두상 포함) · 굵은 요약 + 작은 세부 설명
  - 상세: 페어명(+ 페어 키워드) · 캐릭터 프로필(두상/이름/키워드/간략 프로필) · 관계도 화살표 · 세계관 · 페어 이미지 · 서사 제목 + 타임라인 · 테마곡(앨범 커버/곡 정보/가사) · 대표 대사(말풍선)
- **이미지 칸 크기**: 비율에서 “직접 정하기”를 고르면 높이를 px로 자유롭게 정할 수 있고, 너비(%)와 정렬도 바꿀 수 있어요. 테마곡 커버 칸 너비·높이, 대사 두상 크기도 조절돼요.
- **슬라이드 바 + 숫자 입력**: 모든 슬라이드 바 옆 숫자 칸에 값을 직접 입력할 수 있어요(Enter로 적용).
- **블록 편집**: 정해진 가로 폭 안에서 줄을 여러 칸으로 나누고(칸 너비 비율 조절), 블록을 추가·복제·삭제·끌어서 이동. 세로 길이는 내용만큼 늘어납니다.
- **글자 꾸밈**: 모든 글자를 캔버스에서 바로 고치고, 선택하면 글꼴 · 크기 · 굵게/기울임/밑줄/취소선 · 글자색 · 형광펜 · 정렬을 바꿀 수 있습니다.
- **글꼴**: 기본 제목·영문 라벨 `페이퍼로지(Paperlogy)`, 본문 `코펍월드 돋움체(KoPubWorld Dotum)`. 프리텐다드도 고를 수 있어요. 글꼴 파일(ttf/otf/woff/woff2)을 올리거나 눈누 등의 `@font-face` CSS를 붙여 넣어 내 글꼴을 추가할 수 있습니다.
- **스티커**: 배경이 투명한 PNG를 여러 장 올려 붙이고, 드래그로 이동 · 모서리로 크기 · 위쪽 손잡이로 회전(Shift = 15° 단위), 투명도 · 좌우 반전 · 블록 뒤로 보내기.
- **테두리 방식**: 블록마다 테두리 / 페이지 전체를 감싸는 테두리 / 둘 다 / 없음. 페이지 테두리는 두께 · 색 · 둥글기 · 바깥 간격 · 안쪽 면 색을 따로 정할 수 있어요.
- **배경**: 단색 · 그라데이션(직선/원형, 2~3색, 각도·중심) · 이미지(꽉 채우기/전체 보이기/바둑판 반복, 위치, 진하기). 블록 면 색을 없애서 배경이 비쳐 보이게 할 수도 있어요.
- **색 커스텀**: 바탕 · 카드 · 테두리 · 글자 · 캐릭터 A/B 색 · 태그 · 형광펜 · 선 등 모든 색을 바꿀 수 있고, 블록마다 면/테두리/글자 색을 따로 지정할 수 있습니다. 프리셋 5종 포함.
- **저장**: 편집 내용은 브라우저(IndexedDB)에 자동 저장되고, **내 페어틀**에서 여러 개를 만들어 두고 골라 편집할 수 있어요(열기 · 이름 바꾸기 · 복제 · 삭제).
  다른 기기로 옮기거나 백업할 땐 `저장 파일(.json)`, 이미지로는 `PNG 내보내기`(1~3배 해상도).

## 모바일에서 쓰기
- 아래 탭(블록 · 디자인 · 스티커 · 속성 · 미리보기)을 누르면 아래에서 패널이 올라와요.
- 캔버스의 글자를 누르면 큰 **글 편집 창**이 열리고, 위쪽 꾸밈 막대로 글꼴 · 크기 · 색 · 형광펜을 바꿀 수 있어요.
- 블록을 누르면 아래에 조작 막대가 나와요: 위/아래 · 왼쪽/오른쪽 칸으로 옮기기 · 복제 · 삭제 · 속성.
- 키워드(해시태그)는 블록 속성의 “키워드”에서 추가 · 순서 변경 · 삭제할 수 있어요.

## 구조
```
index.html
css/  fonts.css(기본 글꼴) · app.css(편집기 화면) · frame.css(페어틀 디자인)
js/   core.js(상태·저장·되돌리기) · blocks.js(블록 종류·템플릿) · richtext.js(글자 꾸밈)
      render.js(캔버스·블록 이동·확대) · stickers.js · inspector.js(속성/디자인 패널) · app.js(시작·내보내기)
lib/  html-to-image.js (MIT, PNG 내보내기용)
```
